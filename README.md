# JavaScriptレベル10

レベル1〜9では、1つのファイルをその場で実行しながら、JavaScriptの文法やデザインパターンを学んできました。レベル10では、そこから一歩進み、`npm`や`pnpm`といったツールを使って、複数のファイルやパッケージからなる<span class="info">「プロジェクト」</span>を管理する方法を学びました。

このレベル11では、その延長線上で、いよいよ<span class="info">「ブラウザで動くアプリケーションを作る」</span>ための準備として、<span class="info">ビルドツール</span>について学んでいきます。これまでのレベルでは、`Node.js`環境の中で、書いたコードをそのまま実行できていました。しかし、ブラウザに向けてアプリケーションを配布するには、複数のファイルを1つにまとめたり、`npm`でインストールしたパッケージをブラウザで動く形に変換したりといった、<span class="marker">「ビルド」と呼ばれる作業が必要になります。</span>

このレベルでは、数あるビルドツールの中でも、現在主流となっている<span class="info">「Vite」</span>を中心に扱います。まず、ビルドツールがなぜ必要とされるようになったのか、その歴史的な背景を押さえたうえで、実際に`Vite`でプロジェクトを新しく作成し、開発サーバーを起動してみます。ファイルを保存すると画面が即座に更新される、ホットリロード（HMR）という開発体験も体験します。

さらに、実際にアプリケーションを配布するための、<span class="info">本番用ファイルのビルド方法</span>や、<span class="info">開発中と本番とで異なる設定を切り替える、環境変数の使い方</span>までを学びます。このレベルを終える頃には、HTML・CSSをまだ知らなくても、<span class="marker">「JavaScriptのプロジェクトを、ブラウザで動く形に組み立てる」</span>という一連の流れを、自分の手で体験できるようになっています。

## 内容
JavaScriptレベル11では以下のテーマを取り扱います。

* ビルドツール
* vite
* 開発用サーバーの起動
* 本番用ビルド作成
* 本番用ビルドの表示
* 環境変数

「ECMAScript2015」以降に準拠していますが、本カリキュラムでは上記の分野のみを取り扱います。
